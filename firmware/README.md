
# GaitSense — Hardware Development

## Project
IoT-Based Wearable System for Real-Time Gait Anomaly Detection and Sensory Cueing

## Hardware Components
- ESP32 DevKit V1
- MPU6050 accelerometer and gyroscope
- Vibration motor
- Compatible motor driver

## Hardware Objectives
1. Collect movement data using MPU6050.
2. Process sensor measurements using ESP32.
3. Identify candidate gait anomalies using computational rules.
4. Activate vibration feedback.
5. Send event records to Firebase.
